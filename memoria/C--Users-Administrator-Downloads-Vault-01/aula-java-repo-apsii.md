Aula de GitHub/Java (IntelliJ). Repo: https://github.com/cauedev30/apsii, branch `main`, uma pasta por aula (`exercicio1`, `caue-aula2`, `aula 3`). Cópia local em `C:\Users\Administrator\Downloads\apsii`.

Regra fixa do usuário: **nada de marca de IA**. Commit sem `Co-Authored-By: Claude`, código sem comentário/cabeçalho gerado, mensagem de commit no português informal dele (ex.: `exercício 2, feito em sala`). Ele quer código de aluno iniciante — só o básico, igual à print do professor.

**Why:** o trabalho é avaliado pelo professor; qualquer rastro de IA compromete.
**How to apply:** commitar com `git commit -m` puro, conferir `git log -1 --format=%B` antes do push. Ver [[um-passo-de-cada-vez]].
