O padrão de organização do Cauê é **um MazyOS por cliente**, não um workspace
único de freelancer com vários clientes dentro.

Instalações conhecidas em 08/09/2026:
- `Desktop/ilovebikini/` → cliente i love bikini (`clientes/i-love-bikini/site`)
- `Desktop/eme praia/` → cliente Eme Praia (`clientes/eme-praia/`)

**Why:** significa que uma pasta raiz com nome de cliente está correta, não é
erro de nomenclatura. Não sugerir renomear a raiz nem consolidar os workspaces.

**How to apply:** ao abrir um workspace desses, esperar encontrar um só cliente
dentro de `clientes/`. Cliente novo = MazyOS novo.
